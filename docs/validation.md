本页公开匿名汇总，不包含真实房间 ID、游客身份、评论原文、运行日志或个人文件路径。房间 A–E 仅表示本轮测试的五个配置项，顺序固定，不用于对外识别直播间。

## 离线基线

架构整理前，Node.js 24.19.0 执行 **31 项离线测试，全部通过**。测试使用模拟网络、临时时间与数据库，不自动访问直播间。

覆盖游客确认、鉴权进房次序、ACK/心跳超时、停止中断、重连、房间过滤、长整数精度、持久化去重、文件替换失败恢复、48 小时过期边界、前置 5 分钟窗口、分页、管理接口、绝对截止、同一测试恢复及配置开关跨进程保持。

这是重构前基线；当前源码请运行 `npm run check` 获取实际结果，新增测试数量以测试输出为准。模拟时钟的 48 小时边界通过，不代表已真实连续运行满 48 小时。

## 一轮实际游客测试

观察时间：**2026-10-14 北京时间 14:43:41–17:00**。计划到期正常停止，累计 **132 条真实文字评论**。

| A        |             21 | 曾成功采集，约 16:01 收到关播信令     |
| B        |             49 | 采集至计划截止                        |

五个房间均确认 `guest=true`，独立游客身份校验通过。五房间全部订阅的共同窗口为 **0**，五路共同文字验收 **未通过**。三个有文字房间的共同订阅累计约 **77 分 55 秒**，该交集内有 **75 条评论**；这一子集结果不能代替五路验收。

0 评论不等于断线，但也不能声称文字采集成功。关播后的关闭响应包含重复进房尝试，不能按响应次数计算独立关播事件。

## 恢复、缓存与资源

执行两次受控进程恢复：一次强制退出后由监督程序拉起，一次配置关闭与服务重载。两次均保持原测试、原截止和已有评论 ID。约 14:51、15:06 的恢复造成订阅间隙，因此本轮不是全程连续采集；异常退出的旧在线区间按最后记录帧保守封口。

最终 **73 个分钟 JSON、132 条评论**与 SQLite 逐条核对一致。有文字的三个房间固定字段、北京时间 `+08:00`、时间戳 ID、房间归属和同房 ID 唯一性校验通过；两个无文字房间无法完成字段实测。未发现额外服务故障或踢出。

最后一个服务进程的采样峰值 RSS 约 **85.3 MiB**，平均 CPU 约 **0.2%（单核 100% 口径）**。重启前后的数据分属不同进程，前序末次快照指标不完整，不能据此宣称全程资源峰值。累计记录 WS 收发应用负载约 **20.9 MiB**，不包含 TLS/TCP 头、视频、浏览器或完整网络开销。
